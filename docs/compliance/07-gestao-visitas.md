# 07 — Guia para Gestão de Visitas

Procedimentos para visitas de entidades reguladoras, autoridades e prestadores de serviços.

- **Visitantes Oficiais — acompanhamento obrigatório** — Reguladores, agências governamentais e investigadores — nunca desacompanhados
- **Verificação de identidade** — Obrigatória para representantes de autoridades reguladoras e policiais
- **Transmissão de documentos proibida** — Expressamente proibida sem validação prévia por um Acompanhante autorizado
- **Visitantes de Longa Duração** — Auditores e consultores — verificação de identidade + cartão de acesso
