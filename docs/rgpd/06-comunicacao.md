# 6. Comunicação de Dados Pessoais

Os Dados Pessoais podem ser comunicados a sociedades em relação de grupo ou de domínio com a Circle, ou
tratados por entidades subcontratadas para esse efeito. Podem também ser transmitidos a autoridades
judiciais, administrativas, de supervisão ou regulatórias, para cumprimento de obrigações legais e
regulamentares.
