# Perguntas Frequentes

??? question "Não consigo ver uma secção que deveria estar aqui — o que faço?"
    Confirmem primeiro se estão a olhar no separador certo (Geral, Comercial, Risco ou Compliance). Se
    mesmo assim não encontrarem, ver [Como Usar / Pedir Ajuda](ajuda.md).

??? question "Como pesquiso por um termo específico?"
    Usem a caixa de pesquisa no topo da página — pesquisa em todo o conteúdo do site, não só nos títulos.

??? question "Posso editar uma página diretamente no site?"
    Não — esta intranet é gerada a partir de ficheiros Markdown num repositório GitHub. Editar significa
    mudar o ficheiro correspondente e enviar (`git push`); o site atualiza-se sozinho a seguir.

??? question "Uma sigla que vi aqui não está a fazer sentido — onde vejo o significado?"
    Ver o [Glossário](glossario.md), na secção Geral.

??? question "Quem devo contactar sobre um erro no conteúdo de Compliance?"
    O Responsável de Compliance — ver [Equipa e Organograma](../equipa/organograma.md) para o contacto.

??? question "Esta intranet funciona no telemóvel?"
    Sim — o site adapta-se automaticamente a ecrãs mais pequenos.

??? question "Como mudo entre modo claro e escuro?"
    Há um ícone no canto superior direito de qualquer página para alternar.
