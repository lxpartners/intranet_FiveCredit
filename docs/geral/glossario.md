# Glossário

Siglas e termos usados ao longo desta intranet. Para sistemas e ferramentas com mais detalhe, ver
[Sistemas e Ferramentas](sistemas-ferramentas.md).

| Sigla / Termo | Significado |
|---|---|
| **Algebra Capital** | Entidade responsável pelo Office Support (correspondência registada) e pela gestão do contencioso — ver [Sistemas e Ferramentas](sistemas-ferramentas.md) |
| **AM04** | Código de retorno bancário para "insuficiência de fundos", usado nas comunicações de falha de débito direto — ver [Gestão de Incumprimentos](../compliance/gestao-incumprimentos.md) |
| **AML** | Anti-Money Laundering — prevenção de branqueamento de capitais |
| **AT** | Autoridade Tributária e Aduaneira |
| **BDP** | Banco de Portugal |
| **BIC** | Bank Identifier Code — código internacional do banco, usado juntamente com o IBAN (também chamado SWIFT-BIC) |
| **CA** | Conselho de Administração |
| **CC** | Contabilista Certificado (também referido como TOC) |
| **Circle Capital SGOIC** | Sociedade Gestora de Organismos de Investimento Coletivo do grupo — ver [Sistemas e Ferramentas](sistemas-ferramentas.md) |
| **CIRE** | Código da Insolvência e da Recuperação de Empresas |
| **CITIUS** | Portal público dos tribunais portugueses, usado para consultar a Lista Pública de Execuções e processos de insolvência (CIRE) |
| **CMVM** | Comissão do Mercado de Valores Mobiliários |
| **CRC** | **Atenção — sigla usada com dois significados diferentes nesta intranet:**<br>1) *Certidão do Registo Comercial* — no [Fluxo de Trabalho](../fluxo-trabalho/fase-2-candidatura.md), para verificar elegibilidade e criar a estrutura do KYC<br>2) *Central de Responsabilidades de Crédito* — na [Gestão de Incumprimentos](../compliance/gestao-incumprimentos.md), o registo de crédito do Banco de Portugal |
| **Credit Cover** | Motor interno de cálculo de juros, reporte financeiro e faturação — ver [Sistemas e Ferramentas](sistemas-ferramentas.md) |
| **Creditscore** | Plataforma principal de candidatura e gestão de financiamentos — ver [Sistemas e Ferramentas](sistemas-ferramentas.md) |
| **DD** | Débito Direto |
| **DMIS** | Declaração Mensal de Imposto do Selo |
| **Doc Sync** | Ver *Five Credit Doc Sync* |
| **DPO** | Data Protection Officer — Encarregado de Proteção de Dados |
| **ESG** | Environmental, Social and Governance — critérios ambientais, sociais e de governação |
| **Five Credit Doc Sync** | Extensão do Google Chrome para recolha automática de documentos — ver [Sistemas e Ferramentas](sistemas-ferramentas.md) |
| **Five Extractor** | Aplicação usada pelo Contabilista Certificado para extrair dados do SAFT — ver [Sistemas e Ferramentas](sistemas-ferramentas.md) |
| **IBAN** | International Bank Account Number — número de conta bancária internacional |
| **IMI** | Imposto Municipal sobre Imóveis |
| **IRS** | Imposto sobre o Rendimento das Pessoas Singulares |
| **KYC** | Know Your Customer — processo de identificação e verificação do cliente |
| **KYC.FiveCredit** | Portal de gestão do processo de KYC usado pelo Compliance — ver [Sistemas e Ferramentas](sistemas-ferramentas.md) |
| **Marathon** | Sistema que envia a informação de débitos diretos ao Bankinter — ver [Sistemas e Ferramentas](sistemas-ferramentas.md) |
| **NIB** | Número de Identificação Bancária |
| **NIF** | Número de Identificação Fiscal |
| **Office Support** | Equipa da Algebra Capital responsável pelo envio de correspondência registada aos clientes |
| **PEP** | Pessoa Politicamente Exposta |
| **RCBE** | Registo Central do Beneficiário Efetivo |
| **RGPD** | Regulamento Geral de Proteção de Dados |
| **SABI** | Sistema de Análise de Balanços Ibéricos (base de dados financeira) — já não é referido como fonte de dados no Fluxo de Trabalho atual |
| **SGOIC** | Sociedade Gestora de Organismos de Investimento Coletivo |
| **Sibs** | Rede de processamento de pagamentos usada nos débitos diretos — ver [Sistemas e Ferramentas](sistemas-ferramentas.md) |
| **SS** | Segurança Social |
| **TOC** | Técnico Oficial de Contas (ver CC) |

!!! tip
    Se encontrarem uma sigla nesta intranet que não esteja aqui, adicionem uma linha a esta página — é o
    tipo de conteúdo que compensa manter sempre atualizado.
